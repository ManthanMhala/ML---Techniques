# 🤖 ML - Techniques

A collection of **7 Machine Learning algorithms implemented using Python** to explore model training, predictive modeling, and performance evaluation.

## 📌 Overview

This repository contains implementations of fundamental Machine Learning algorithms using popular Python libraries. It is designed to build practical knowledge of machine learning concepts and understand how different algorithms solve prediction and classification problems.

## 🧠 Algorithms Implemented

The following machine learning techniques are covered in this repository:

1. **Logistic Regression** – A supervised learning algorithm used primarily for classification tasks.
2. **Decision Tree** – A tree-based algorithm used for classification and regression.
3. **K-Nearest Neighbors (KNN)** – A distance-based algorithm that predicts outcomes using the nearest data points.
4. **Support Vector Machine (SVM)** – An algorithm that finds an optimal decision boundary to separate classes.
5. **Random Forest** – An ensemble algorithm that combines multiple decision trees to improve predictive performance.
6. **Gradient Descent** – An optimization technique used to minimize a model's loss function by iteratively updating parameters.
7. **Ensemble Learning** – A technique that combines multiple models to improve prediction accuracy and robustness.

## 🛠️ Technologies Used

The project uses the following Python libraries and tools:

- **Python** – Core programming language.
- **NumPy** – Numerical computing and array operations.
- **Pandas** – Data manipulation and analysis.
- **Scikit-learn** – Machine learning model implementation and evaluation.
- **Matplotlib** – Data visualization and plotting.
